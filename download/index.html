File instalasi resmi disediakan oleh Hello Majesty. Jika tombol belum aktif, coba muat ulang halaman beberapa saat lagi.

Cara memasang di Android

  1. Tekan tombol Download APK Terbaru.
  2. Buka file APK yang sudah selesai diunduh.
  3. Jika diminta, izinkan instalasi aplikasi dari sumber ini.
  4. Tekan Install atau Update.
  5. Buka Hello Majesty dan izinkan notifikasi agar pemberitahuan dapat diterima.

Instal di iPhone / iPad

Hello Majesty tersedia sebagai Web App. Tidak perlu App Store atau Apple Developer Account.

  1. Buka halaman ini menggunakan Safari di iPhone atau iPad.
  2. Tekan tombol Bagikan (ikon kotak dengan panah ke atas).
  3. Pilih Tambahkan ke Layar Utama / Add to Home Screen.
  4. Pastikan opsi Open as Web App aktif jika ditampilkan, lalu tekan Add.
  5. Buka ikon Hello Majesty dari Layar Utama dan login seperti biasa.
Buka Hello Majesty di iPhone

Notifikasi iPhone akan disiapkan pada tahap berikutnya. Untuk Web Push, iPhone/iPad memerlukan iOS/iPadOS 16.4 atau lebih baru dan aplikasi harus dibuka dari ikon Layar Utama.
